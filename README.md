What I build
Most of my technical work comes from a simple question: why are we still doing this by hand?
Case management automation: Used Google Apps Script, refined with Gemini AI, to find duplicate cases and consolidate related ones by customer attributes. It cleared a backlog of just over 9,000 cases.
Alert threshold analysis: Used SQL and Power BI to test where an alert rule should sit. The result was a $12K / 14-day threshold that captured 92.48% of confirmed fraud cases.
Triage and tracking tools: Built case triage tools and a multi-country SAR/STR/SMR filing tracker with automated date-stamping.
My rule for automation in compliance is to clear the noise so people can spend their time on the judgment calls.
